### 1. arXiv 7-27 论文:回归税(Regression Tax)解构 LLM Agent 技能迁移的代价
📰 arXiv / 2026-07-27 | http://arxiv.org/abs/2607.22520
来自学术圈的本周新研究关注 LLM Agent 的**技能迁移成本** — 当 Agent 通过 SFT/RL 习得的"技能(组合能力)"被迁移到新任务环境时,实际性能经常低于基线,这部分被作者命名为"regression tax"。论文系统拆解了导致 skill 冲突、过去学习遗忘、新任务表征冲突三方面的因子。**与你 AI Coding 系列相关**:复用 agent skill 包时,模块之间的隐性冲突正是阻碍复用的关键因素,这篇论文提供了第一手量化分析。

### 2. arXiv 7-27 论文:κ-LoRA 用条件数定位真正需要更新的 LoRA 矩阵
📰 arXiv / 2026-07-27 | http://arxiv.org/abs/2607.22489
来自 Marco Canini 团队的 KAUST 研究提出 **κ-LoRA**:通过 Hessian 矩阵条件数识别哪些 LoRA 矩阵在微调时真正"值得更新",其余矩阵跳过。核心结论:**典型的 LoRA rank=8 配置中只有约 30% 的矩阵真正起作用**,其余是冗余更新。这大幅降低 PEFT 显存与算力开销,在多任务合并(Adapter Fusion)与持续学习场景直接受益。**对 B2B 实际工程意义**:持续微调企业内部场景化模型时,可精确切片"该不该更"。
