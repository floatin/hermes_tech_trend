# AI Daily Brief · 每日科技早报归档

每天 8:30 (Asia/Shanghai) 自动生成的科技早报存档目录。

## 目录结构

    ai-daily-brief/
    ├── README.md                   本文件
    ├── YYYY-MM-DD.md               当日图文早报(纯文本+链接,可直接转发)
    └── audio/
        └── YYYY-MM-DD.mp3          当日 TTS 早报语音(推微信时作为附件)

## 内容范围

- **国内 10 条 + 国外 10 条** 标准模式（连续真新 N≥1 时）
- **降级模式**（mmx 池耗尽时）:B_degrade_to_minimal_extreme = 3+2 / 1+2+2 = 5 条
- **静默模式**（N=0 且 carry-over 池也枯竭,但仍走 fallback 3+2 模式）
- 范围严格限定:**纯 AI/算法主题**。不收录:商业航天、纯财务/IPO 公告、宏观经济、传统半导体(除非和 AI 算力强相关)、新能源、汽车
- 主题词:大模型 / LLM / 多模态 / RLHF / 对齐 / Agent / AI 芯片 / GPU / HBM / AI Infra / 训练推理框架 / 国产 GPU / RAG / 向量 / 世界模型
